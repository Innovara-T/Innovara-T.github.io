# Emmanuel Uche · Portfolio

A dependency-free portfolio. Open `index.html` to preview it, or serve this directory with `python -m http.server 8000`.

## GitHub Pages

1. Create a public repository. Use `Innovara-T.github.io` for a portfolio at `https://innovara-t.github.io/`, or `portfolio` for a project under an existing profile site.
2. Upload `index.html`, `styles.css`, `icon.png`, and `.nojekyll` to the repository root.
3. Under **Settings → Pages**, select **Deploy from a branch**, choose your default branch and **/ (root)**, then save.
4. Once the Pages deployment succeeds, open the reported URL in a private browser window and check the links.

## Vercel

Import the source repository, select **Other** as the framework preset, keep the repository root as the root directory, and deploy with the default empty build command. The site serves the files directly.
